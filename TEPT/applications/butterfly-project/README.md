# Butterfly Project (planned)

Purpose: explore alternative timelines. A user changes an event, such as a departure time, and compares how the sequence of interactions and downstream events changes.

Planned components:

- Timeline branching and event graphs (NetworkX).
- Multiple interacting agents.
- Alternative scenarios and Monte Carlo experiments.
- High-impact event identification, with uncertainty.

Status: not started. Depends on the shared research engine (temporal event representation, agent interactions, scenario comparison, probability estimation, impact analysis, uncertainty reporting). The project does not claim to predict life-changing events; the first domain is road traffic because it is measurable.
