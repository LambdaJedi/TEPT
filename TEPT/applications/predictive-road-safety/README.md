# Predictive Road Safety Network (planned)

Purpose: estimate dangerous vehicle interactions and explore possible interventions.

Planned components:

- Vehicle trajectory prediction.
- Time-to-collision and conflict estimation.
- V2X communication research.
- Local warnings and controlled intervention experiments.

Status: not started.

## Safety-engineering workstream (required before any real-world proposal)

False-positive warnings, communication latency, sensor errors, cybersecurity and privacy must be addressed first. An automatic braking feature must never be treated as safe merely because a simulation suggests it works. Models calibrated on foreign datasets are not validated for South African conditions.
